# Smart7z

by **Kurpphy** · [GPLv3](LICENSE)

面向 Windows 的图形化批量解压工具。把压缩包加入队列后，Smart7z 识别分卷、尝试密码、解压和校验，再把通过检查的输出放到最终位置。默认保留源文件。

## 下载

在 [GitHub Releases](https://github.com/ackcsa/Smart7z/releases) 下载发行包，以 Release 页面标注的版本和附件为准。本地 `release/` 目录可能含未发布候选，不能据此判断是否已发布。

| 文件 | 适用场景 |
| --- | --- |
| `Smart7z-<版本>-setup-windows-x64.exe` | 安装使用，可覆盖升级。 |
| `Smart7z-<版本>-portable-windows-x64.zip` | 免安装，完整解压到可写目录后运行。 |
| `Smart7z-<版本>-source.zip` | 开发、测试和构建，含对应第三方源码及许可证。 |
| `SHA256SUMS-<版本>.txt` | 核对以上三个附件的 SHA-256。 |

安装版和便携版自带 Python、PySide6 和 7-Zip，面向 64 位 Windows 10 1809 及以上版本、Windows 11。程序未进行代码签名，首次运行可能出现 Windows 信誉提示。

## 快速上手

1. 安装后启动，或完整解压便携包后运行 `Smart7z.exe`。
2. 勾选“解压到原目录”可把结果放在源包旁边；取消勾选后指定统一目标目录。
3. 少量文件用“添加文件”或拖入窗口，整批文件用“扫描文件夹”。
4. 检查队列并点“开始”，需要密码或候选确认时按提示处理。
5. 检查输出。失败和“部分恢复”不代表完整解压成功。

首次使用保持“保留”清理策略。清理策略在任务接收时固定，切换设置只影响之后新增的任务，不改变排队、等待或执行中的任务。即使只有排队或等待任务，关闭窗口也需要确认；退出后未完成任务需要重新添加。

## 常用功能

| 需要 | 功能与注意事项 |
| --- | --- |
| 批量解压或处理分卷 | 自动排队、合并同组分卷，小包优先；同组分卷放在同一目录。 |
| 一批包使用相同密码 | 使用主密码或密码本；成功密码优先用于同批后续任务，并尝试写入明文密码本。不要分享密码本。 |
| 从视频中寻找内嵌 ZIP | 默认兼容扫描支持特定 MP4/MKV 布局；未知布局可对少量文件使用深度扫描，读取量会增加。 |
| 选择内嵌候选 | 唯一精确候选可自动继续；“推荐”只是预选，不代表内容可信。多候选或边界不确定时需人工选择。 |
| 暂存盘空间不足 | 可关闭“暂存模式”，改在目标盘临时目录解压；两种模式都校验后再提交。 |
| 取消任务 | “取消选中”移除所选未完成任务并请求停止其中的活动任务；“取消所有待处理”保留当前任务继续运行。取消本身不删除源包。 |
| 成功后整理源包 | 选择“回收站”或“永久删除”；回收站不可用时的永久删除回退默认关闭。 |

安装版、便携版和源码版在当前用户登录会话内共用一个窗口和队列，但不合并配置、密码本或恢复记录。本版本没有多实例开关；升级前请先关闭旧版窗口。

## 源码运行

源码在 `01_MainProgram/smart7z/`。需要 64 位 Python、PySide6 和可用的 7-Zip；开发环境准备见[维护指南](MAINTENANCE.md#开发环境)。

```powershell
Set-Location 01_MainProgram/smart7z
python smart7z.py
```
