# Smart7z

Smart7z 是面向 Windows 的图形化批量解压工具。把压缩包加入队列后，它逐个识别分卷、尝试密码、解压和校验，再把通过检查的输出放到最终位置。默认保留源文件。

## 快速上手

1. 安装版安装后启动；便携版先完整解压到可写目录，再运行 `Smart7z.exe`。两者都自带 7-Zip 和图形界面依赖。
2. 勾选“解压到原目录”可把结果放在源包旁边；取消勾选后，指定统一的目标目录。
3. 第一次使用保持“保留”清理策略，确认输出后再考虑回收或删除源包。
4. 少量文件用“添加文件”或拖入窗口；整理整批文件用“扫描文件夹”。
5. 检查队列并点“开始”。需要密码或候选确认时按提示处理；失败和“部分恢复”不代表完整解压成功。

## 功能怎么选

| 你的需要 | 功能用途与影响 |
| --- | --- |
| 一次解压很多包或一组分卷 | 自动排队、合并同组分卷，小包优先；分卷应放在同一目录。 |
| 一批包使用相同密码 | 填“主密码”或使用密码本。成功密码优先用于同批后续任务，也会尝试写入明文密码本；不要分享密码本。 |
| 从目录里找出压缩包 | 默认兼容扫描还会寻找支持布局的 MP4/MKV 内嵌 ZIP；未知布局可对少量文件用深度扫描，读取量会增加。 |
| 内嵌 ZIP 弹出候选选择 | 精确验证的唯一候选自动继续；“推荐”只帮你预选，仍需确认，不代表文件内容可信。多候选或边界不确定时须人工选择。 |
| 临时盘空间不够 | 可关闭“暂存模式”，让初始解压发生在目标盘的临时目录；两种模式都校验后再提交，不是关闭安全检查。 |
| 不想继续某个任务 | “取消选中”移除所选未完成任务，并请求停止其中的活动任务，不是删除源包。“取消所有待处理”保留当前任务继续运行。 |
| 解压成功后整理源包 | “回收站”和“永久删除”才涉及源文件清理；回收站的永久删除回退默认关闭。重要资料先保留，详见[清理说明](smart7z_user_manual.html#cleanup)。 |

仓库中的手册是工作树文档；已发布包里的 `Smart7z-User-Manual.html` 是打包时的副本，不会随工作树修改自动更新。启动测量结果和复测入口见[启动诊断报告](.sandbox-test/startup-phases/REPORT.md)。

## 源码运行

源码位于 `01_MainProgram/smart7z/`，需要 Python、PySide6 和可用的 7-Zip；安装版、便携版用户不需要自行安装 Python。

```powershell
Set-Location 01_MainProgram/smart7z
python smart7z.py
```

环境说明和开发操作见[维护与交接指南](MAINTENANCE.md)。
