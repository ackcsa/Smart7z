# Smart7z

Smart7z 是面向 Windows 的图形化压缩包发现、预检、解压、校验和源文件清理工具。发行版内置 7-Zip，源码使用 Python 3.12 和 PySide6。

## 当前界面

- 图形界面真源是 `01_MainProgram/smart7z/ui_qt.py`，入口 `smart7z.py` 只启动 PySide6/Qt 应用。
- 顶部提供“右键菜单”“文件扫描模式”和“选项”；三种扫描模式互斥选择，“选项”打开设置对话框。
- 主界面直接切换“嵌套解压”，最大嵌套深度与“空间不足时等待”在“选项”中设置。
- 扫描进度、手动密码和隐写候选共用非常驻活动栏；任务队列与“任务详情 / 运行日志”之间使用可拖动的垂直分隔条。
- Windows 下再次启动会优先把请求交给现有实例；现有实例正在关闭时，新进程会有界等待转交或取得互斥量后接管，不创建并行任务窗口。
