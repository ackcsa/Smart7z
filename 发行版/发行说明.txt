启动与资源优化
--------------
- 新增 Smart7zShell.exe 轻量右键入口；已有实例时直接完成认证 IPC，不加载 Python 和 Qt。
- 去掉固定 100 ms 的启动排队等待，并在无主实例时先检查命名互斥量，避免等待陈旧 IPC 状态。
- Windows 启动路径不再在首屏调用昂贵的字体精确匹配；隐藏活动提示区和空任务表模型改为首次需要或首轮事件循环后延迟构建。
- 本机抽测已有实例交接约 90-110 ms，原入口约 214-230 ms；峰值工作集约 24-28 MiB，原入口约 30 MiB。
- 最终便携包冷进程右键解压并自动退出抽测约 2.96 秒；启动器缺失时仍会自动回退主程序，功能不降级。

其他更新
--------
- 修复单实例启动、关闭阶段任务转交与恢复状态的竞态，避免请求丢失或并发打开恢复日志。
- 修复嵌套深度 0、一次性密码残留、任务排序、输入选中态和若干 Qt 界面回归。
- 保留并完善 SteganographierGUI 兼容扫描、ZIP64 候选识别、安全切割、嵌套保护、有界流式清单解析和密码候选策略。
- 全量自动化测试 385 项全部通过；安装器使用 Inno Setup 7.0.2 x64 构建。

安装与数据
----------
- 安装版按当前用户安装到 %LOCALAPPDATA%\Programs\Smart7z，可直接覆盖升级。
- 覆盖安装不会覆盖已有非空 code.txt；配置和恢复状态保存在 %LOCALAPPDATA%\Smart7z。
- 首次运行默认保留源压缩包，只有明确选择“回收站”或“永久删除”才会清理。
- 程序自带 7-Zip 命令行组件，无需另行安装 7-Zip。
- 支持 64 位 Windows 10 1809 及以上版本和 Windows 11。
- 程序未进行代码签名，首次启动可能出现 Windows 信誉提示。
