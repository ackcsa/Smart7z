Smart 7z Ultra 1.0.2 安装版（Windows x64）
================================================

使用方法
--------
1. 从开始菜单启动 Smart 7z Ultra。
2. 可使用按钮、拖拽、命令行或已添加的右键菜单添加压缩包。
3. 完整中文说明见安装目录中的 Smart7z-User-Manual.html。

右键窗口
----------
- 仅由资源管理器右键菜单独立创建的窗口，会在全部任务无异常完成后自动关闭。
- 普通窗口接收右键任务不会自动关闭；右键窗口随后被双击激活，也会保留。
- 失败、部分恢复、中断、需密码、候选复核、扫描失败或其他通知都会保留窗口供检查。
- 多选右键恰逢旧实例关闭时，新进程会等待请求转交或取得启动互斥量后接管，不会同时打开恢复日志。

本次更新
--------
- 修复部分 ZIP 在 7-Zip 清单中包含空路径根目录元记录时被误判为非法成员、最终报 INTERNAL_ERROR 的问题；该元记录现在会被忽略，真实文件仍完整预检和解压。
- 修复顶部菜单栏被固定高度裁掉文字的问题，并补充不同窗口尺寸下的菜单几何回归测试。
- 右键短命进程改用独立轻量 IPC 客户端；无主实例时先检查命名互斥量，跳过陈旧状态连接等待；异常诊断模块延后到真正崩溃时加载。
- 隐写深度扫描支持改为首次实际扫描时按需加载；输出目录和主密码输入框在首次交互前使用轻量兼容控件，减少首屏原生控件构造。
- 全局字体和基础颜色改由应用字体与调色板设置，避免通用样式规则在冷启动时重复作用于全部控件。
- 启动请求只在 IPC 确认监听后处理；关闭时保留互斥量直到调度器和 IPC 都真实停止，避免请求丢失或恢复状态并发。
- 修复首次右键窗口被启动时的置前动作误取消自动关闭；成功完成后会按说明自动退出，之后被用户或第二进程激活仍会保留窗口。
- Qt 原生文件与目录拖放已覆盖主窗口队列路径，并补充文件、目录和遮罩状态测试。
- 修复嵌套深度 0 被恢复为 2、一次性密码提交后残留、任务表默认排序和输入控件选中态等界面回归。
- 菜单栏新增“文件扫描模式”三级互斥对钩菜单和“选项 → 空间不足时等待”；下方删除重复的空间等待、深度扫描按钮。默认选择“仅兼容隐写者模式（非全读取）”。
- 隐写者兼容模式支持 SteganographierGUI 的普通 MP4 追加 ZIP、ZArchiver free 原子和 MKV ZIP 附件，只跳读容器元数据并定点校验 ZIP，不顺序读取视频主体。
- 深度扫描、直接添加和拖入也会优先识别隐写者的 ZIP64 结构与随机诱饵尾缀；命中后只保留真实 ZIP 候选，不再把尾部 RAR/7z/ZIP 诱饵交给用户。
- 修复仅兼容隐写者模式在文件夹扫描已找到精确候选后，执行阶段仍按原视频打开并报 NOT_ARCHIVE 的问题；预计算候选现在会直接进入安全切割，超过 4 GB 的 MP4 载体也能正确交给 7-Zip。
- 深度扫描改为单轮流式读取并复用候选，文件夹扫描期间临时显示文件进度，扫描结束后自动收起。
- 任务详情高度可拖动；任务表默认按源包大小升序处理，“源文件”列改为“源包处理”。
- 手动密码提交或跳过后清空输入并收起提示区，恢复任务区域布局。
- 自动候选全部失败后，每次手动提交只尝试本次输入；错误手动密码不会重新遍历本批次成功密码或 code.txt。
- 修复隐写候选处理后可能遗留空 stego 会话目录的问题；仅清理所有权可验证的固定空目录，未登记内容仍会保留。
- 嵌套解压会保护普通 Windows EXE 所在目录和父目录，边界不越过当前输出根；改名压缩包及高置信度 ZIP/7z SFX 仍可处理。
- 复用文件头可见的完整加密清单；同一任务等待手动密码后重试时，源文件未变化也不重复列清单。
- 本批次成功密码优先尝试；已确认加密后跳过必然失败的无密码解压尝试。
- 7-Zip 清单改为有界流式解析；正常包主要降低内存，条目超限时会提前终止列表进程；内部解析安全上限为 200000，配置更高也不会绕过。
- 增加列表、解析、预检、解压、输出扫描和总耗时诊断，不记录密码。
- 自动识别失败后的格式回退优先使用 ZIP/RAR/7z 可靠签名，并限制为一次有依据的重试。

安装数据
--------
- 程序按当前用户安装到 %LOCALAPPDATA%\Programs\Smart7z。
- 配置和恢复状态保存在 %LOCALAPPDATA%\Smart7z；相对密码本通常也放在这里。若旧安装目录已有非空密码本，而状态目录没有有效密码本，程序会继续使用旧地址。
- 首次运行默认保留源压缩包；只有明确选择“回收站”或“永久删除”才会清理。
- 首次安装时随附的 code.txt 为空，请按“一行一个密码”自行添加密码候选；覆盖安装和升级不会覆盖已有文件。
- 卸载会保留用户配置、密码本和恢复数据，避免误删。
- 程序已自带 7-Zip 命令行组件，无需另装 7-Zip。
- 可直接覆盖安装同一版本或升级安装；安装器会替换程序文件，但保留已有 code.txt、用户配置和恢复数据。原安装地址存在非空密码本时，程序不会用新的空占位替代它。覆盖前请先关闭正在运行的 Smart7z。

说明
----
- 支持 64 位 Windows 10（1809 及以上）和 Windows 11。
- 程序未进行代码签名，首次启动可能出现 Windows 信誉提示。
- 第三方许可证位于 licenses 文件夹及程序目录。
- 发布前请使用 SHA256SUMS.txt 校验安装器。
