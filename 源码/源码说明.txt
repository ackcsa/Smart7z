Smart 7z Ultra 1.0.2 源码版
===========================

本次更新日期：2026-08-27

文件

源码包内容
----------
- Smart7z 一方 Python 源码、PySide6 界面、测试、构建脚本、资源模板和用户手册。
- 为满足 Qt/PySide6 许可证要求，包含对应源码与相关许可证说明。
- 不包含 build、release、虚拟环境、离线构建工具、缓存或运行时恢复记录。
- resources/code.txt 为空，resources/smart7z_config.json 默认保留源压缩包。

1.0.2 主要变化
--------------
- 修复 7-Zip SLT 清单中空路径根目录元记录被当成实际成员、导致部分 ZIP 报 INTERNAL_ERROR 的问题。
- 修复顶部菜单裁切、文件与目录拖放、右键窗口自动退出及多项 Qt 界面回归。
- 新增 shell_launcher.cs / Smart7zShell.exe 轻量右键入口；已有实例时无需加载完整 Python/Qt 运行时。
- Windows UI 启动避免字体数据库精确匹配；隐藏活动提示区和空任务表模型采用延迟构建，降低首屏构造抖动。
- 隐写候选模块改为实际扫描时按需导入；输出目录和主密码输入框先使用兼容原有信号、焦点顺序和辅助功能属性的轻量控件，首次交互时再创建原生 QLineEdit。
- 全局字体与基础颜色改由 QApplication 字体和调色板设置，避免通用样式选择器在冷启动时重复作用于全部控件。
- launch_ipc.py 提供最小认证 IPC 转发边界，runtime_ipc.py 统一单实例状态与关闭协调。
- 保留完整安全预检、SteganographierGUI 兼容探测、ZIP64 几何校验、嵌套保护、密码候选及有界流式 7-Zip 清单解析。
- 相同环境下，从进程启动到进入 Qt 事件循环的冷启动中位数由 3358 ms 降至 2951 ms，约缩短 12%。
- 全量自动化测试 390 项及 155 个子测试全部通过。

运行与验证
----------
- 建议使用 64 位 Python 3.12，并安装 PySide6。
- 安装 7-Zip，或将 7z.exe 放在解压后的源码根目录。
- 启动：python smart7z.py
- 全量测试：python -m unittest discover -s tests -v
- 真实 7-Zip 集成测试：python -m unittest tests.test_integration_real7z -v
- 构建依赖：python -m pip install -r requirements-build.txt
- 构建：powershell -ExecutionPolicy Bypass -File .\build_release.ps1

完整说明见源码包中的 README.txt 和 Smart7z-User-Manual.html。
校验结果应与同目录 SHA256SUMS.txt 一致。
