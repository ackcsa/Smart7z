Smart7z __VERSION__ 安装版（Windows x64）
=======================================

开始使用
--------
1. 从开始菜单启动 Smart7z，添加压缩包后点“开始”。
2. 完整操作和错误说明见 Smart7z-User-Manual.html。
3. 版本变化见 CHANGELOG.md。

数据与升级
----------
- 默认安装到 %LOCALAPPDATA%\Programs\Smart7z。
- 配置和恢复状态在 %LOCALAPPDATA%\Smart7z；相对密码本通常也在这里。
- 若旧安装目录已有非空密码本，而状态目录没有有效密码本，程序可能继续使用旧地址。
- 随附 code.txt 为空。覆盖升级不替换已有密码本；卸载保留配置、密码本和恢复数据。
- 覆盖安装先卸载已登记的旧安装版，再安装新版；旧版卸载失败、取消或需要重启时停止，不继续覆盖文件。卸载完成后若新版安装失败，可重新运行安装器，不承诺自动回滚旧程序。
- 升级会备份现有 Smart7z 右键菜单，并恢复旧卸载器删除的入口；属于旧安装目录的命令更新为新目录，其他副本的入口保留。备份保存在 %LOCALAPPDATA%\Smart7z\upgrade-menus-*。
- 升级前先关闭旧版窗口。卸载只清理本安装目录拥有的右键入口，不移除其他副本接管的入口。

重要行为
--------
- 默认保留源包。清理策略只影响之后新增的任务，不改变排队、等待或执行中的任务。
- 排队、等待和扫描也需要关闭确认；退出后未完成任务需要重新添加。
- 安装、便携和源码副本在当前用户登录会话内共用一个窗口和队列，不合并配置或密码本，没有多实例开关。
- 仅右键菜单独立创建的窗口会在全部任务无异常完成后自动关闭；普通窗口、失败、等待输入或需复核时保留窗口。
- 密码本是明文。不要把个人密码本、配置或恢复记录发给他人。

环境与校验
----------
- 面向 64 位 Windows 10 1809 及以上版本、Windows 11，已自带 Python、Qt 和 7-Zip。
- 程序未签名，首次运行可能出现 Windows 信誉提示。
- 安装前用同一 Release 的 SHA256SUMS-__VERSION__.txt 核对安装器。
- 第三方声明见 THIRD_PARTY_NOTICES.txt；许可证和对应源码说明在 licenses 目录及程序根目录。
- 发行页面：https://github.com/ackcsa/Smart7z/releases
