Smart 7z Ultra __VERSION__ 安装版（Windows x64）
================================================

使用方法
--------
1. 从开始菜单启动 Smart 7z Ultra。
2. 可使用按钮、拖拽、命令行或已添加的右键菜单添加压缩包。
3. 完整中文说明见安装目录中的 Smart7z-User-Manual.html。

右键窗口
----------
- 仅由资源管理器右键菜单独立创建的窗口，会在全部任务无异常完成后自动关闭。
- 普通窗口接收右键任务不会自动关闭；右键窗口随后被双击激活，也会保留。
- 失败、部分恢复、中断、需密码、候选复核、扫描失败或其他通知都会保留窗口供检查。
- 多选右键恰逢旧实例关闭时，新进程会等待请求转交或取得启动互斥量后接管，不会同时打开恢复日志。

本次更新
--------
- 复用文件头可见的完整加密清单；同一任务等待手动密码后重试时，源文件未变化也不重复列清单。
- 本批次成功密码优先尝试；已确认加密后跳过必然失败的无密码解压尝试。
- 7-Zip 清单改为有界流式解析；正常包主要降低内存，条目超限时会提前终止列表进程；内部解析安全上限为 200000，配置更高也不会绕过。
- 增加列表、解析、预检、解压、输出扫描和总耗时诊断，不记录密码。
- 自动识别失败后的格式回退优先使用 ZIP/RAR/7z 可靠签名，并限制为一次有依据的重试。

安装数据
--------
- 程序按当前用户安装到 %LOCALAPPDATA%\Programs\Smart7z。
- 配置、密码本和恢复状态保存在 %LOCALAPPDATA%\Smart7z。
- 首次运行默认保留源压缩包；只有明确选择“回收站”或“永久删除”才会清理。
- 首次安装时随附的 code.txt 为空，请按“一行一个密码”自行添加密码候选；升级不会覆盖已有文件。
- 卸载会保留用户配置、密码本和恢复数据，避免误删。
- 程序已自带 7-Zip 命令行组件，无需另装 7-Zip。
- 可直接覆盖安装同一版本或升级安装；安装器会替换程序文件，但保留已有 code.txt、用户配置和恢复数据。覆盖前请先关闭正在运行的 Smart7z。

说明
----
- 支持 64 位 Windows 10（1809 及以上）和 Windows 11。
- 程序未进行代码签名，首次启动可能出现 Windows 信誉提示。
- 第三方许可证位于 licenses 文件夹及程序目录。
- 发布前请使用 SHA256SUMS.txt 校验安装器。
