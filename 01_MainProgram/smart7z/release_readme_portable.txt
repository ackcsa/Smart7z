Smart7z __VERSION__ 便携版（Windows x64）
=======================================

开始使用
--------
1. 完整解压到可写目录，不要直接在 ZIP 内运行或只复制 EXE。
2. 双击 Smart7z.exe，添加压缩包后点“开始”。
3. 完整操作见 Smart7z-User-Manual.html，版本变化见 CHANGELOG.md。

便携数据
--------
- portable.flag 使配置、密码本和恢复状态保存在本文件夹，请保留该文件。
- 只有 IPC 连接信息写入当前用户的 %LOCALAPPDATA%\Smart7z，以便各副本找到同一窗口。
- 随附 code.txt 为空；密码本是明文，不要随程序文件一起分享。
- 迁移前关闭程序并备份整个文件夹。升级建议解压到新目录，再迁移自己的配置和密码本，不用空模板覆盖个人数据。

重要行为
--------
- 默认保留源包。清理策略只影响之后新增的任务，不改变排队、等待或执行中的任务。
- 排队、等待和扫描也需要关闭确认；退出后未完成任务需要重新添加。
- 安装、便携和源码副本在当前用户登录会话内共用一个窗口和队列，不合并配置或密码本，没有多实例开关。升级前先关闭旧版窗口。
- 仅右键菜单独立创建的窗口会在全部任务无异常完成后自动关闭；普通窗口、失败、等待输入或需复核时保留窗口。

环境与校验
----------
- 面向 64 位 Windows 10 1809 及以上版本、Windows 11，已自带 Python、Qt 和 7-Zip。
- 程序未签名，首次运行可能出现 Windows 信誉提示。
- 解压前用同一 Release 的 SHA256SUMS-__VERSION__.txt 核对 ZIP。
- 第三方声明见 THIRD_PARTY_NOTICES.txt；许可证和对应源码说明在 licenses 目录及程序根目录。
- 发行页面：https://github.com/ackcsa/Smart7z/releases
