Smart 7z Ultra __VERSION__ 便携版（Windows x64）
================================================

使用方法
--------
1. 将完整文件夹解压到可写位置，不要直接在 ZIP 内运行。
2. 请保持文件夹结构完整，Smart7z.exe 依赖同目录组件。
3. 双击 Smart7z.exe 启动，也可以使用按钮、拖拽或命令行添加压缩包。
4. 完整中文说明见 Smart7z-User-Manual.html。

单实例与右键窗口
----------------
- 仅由资源管理器右键菜单独立创建的窗口，会在全部任务无异常完成后自动关闭。
- 普通窗口接收右键任务不会自动关闭；右键窗口随后被双击激活，也会保留。
- 失败、部分恢复、中断、需密码、候选复核、扫描失败或其他通知都会保留窗口供检查。
- 再次启动会优先把请求交给现有窗口；现有实例正在关闭时，新进程会有界等待重新转交或取得启动互斥量后接管，不创建并行窗口、调度器或恢复日志。

便携数据
--------
- portable.flag 使配置、密码本和恢复状态保存在本文件夹。
- 首次运行默认保留源压缩包；只有明确选择“回收站”或“永久删除”才会清理。
- 随附的 code.txt 为空，请按“一行一个密码”自行添加密码候选。
- 备份或迁移时请复制整个文件夹。
- 程序已自带 7-Zip 命令行组件，无需另装 7-Zip。
